BUSCADOR VIN AUTOSUR - INSTALADOR PARA WINDOWS

No requiere Python ni conexion a Internet.

INSTALACION
1. Descomprimi el archivo ZIP completo.
2. Hace doble clic en "Instalar Buscador VIN.cmd".
3. Al finalizar, el programa se abrira y quedara un acceso directo en el escritorio.

El instalador crea una version nueva sin sobrescribir el programa anterior,
por lo que tambien funciona si Windows mantiene bloqueado el ejecutable viejo.

USO
- Pestaña Vehiculos: escribi parte de una patente, modelo o motor.
- Pestaña Clientes: escribi parte del nombre, apellido, DNI o CUIL.
- Los resultados aparecen automaticamente.
- Hace doble clic sobre cualquier celda para copiar ese dato.
- Usa la barra inferior para desplazarte hacia los costados.
- Usa la barra lateral derecha para desplazarte hacia arriba o abajo.
- Pestaña Turnero: carga el PDF de Agenda, elimina los turnos Nissan,
  genera el formato anterior y permite verlo o imprimirlo en A4 vertical.

Compatible con computadoras Windows 10 y Windows 11.
Incluye un icono propio de automovil Renault amarillo.
